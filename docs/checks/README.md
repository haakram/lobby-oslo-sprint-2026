# checks/

Reviews, audits and test reports: security reviews, UX audits, demo dry-run results.

- One file per check: `<kind>-YYYY-MM-DD.md` (e.g. `security-2026-11-08.md`, `demo-dryrun-2026-11-09.md`).
- Each finding gets a line in `PLAN.md` (a task, or the Team review list) so it isn't forgotten here.
