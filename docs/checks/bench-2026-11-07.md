## Offline tune (fix round 1: cart capacity 8 modelled)

Command: `python -m agent tune --seeds 1-20 --trials 30` (about 2.3 min real time). Generated nights from
`agent.bench.offline_scenario(seed)` on the fake server (cart holds 8 items, the 9th pick says "The cart is
full."), 22:00 to 02:00 sim, random search (rng seed 0); sampled `cart_stock` totals at most 7.
Statistic = mean with the worst night dropped.

| Params | mean | mean-drop-worst |
|---|---|---|
| Baseline (`Params()`, default cart stock now totals 7) | 683.5 | 689.6 |
| Best found | 687.0 | 692.8 |

Best (written to `agent/data/params_candidate.json`, NOT auto-loaded): `cart_stock` charger 1, pillow 0,
toiletry 1, towel 4, water 1; `decay_per_min` 0.81; `max_scans` 3; `use_cart` true.

The gain is +3.2 (0.5 %), inside the noise of a 20-night sample. **Offline nights are not yet calibrated to
the live request rate (next task), so the candidate is NOT adopted.** `agent/data/params_best.json` does not
exist; `load_params()` uses `Params()` until one is created deliberately after live validation.
The old default stock (11 items) overfilled an 8-item cart and blocked trays; the default is now 7 items.
