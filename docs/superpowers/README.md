# superpowers/

Written by the superpowers skills, kept in git so the whole team sees the reasoning behind a feature.

- `specs/` — designs from `superpowers:brainstorming`: `YYYY-MM-DD-<topic>-design.md`
- `plans/` — implementation plans from `superpowers:writing-plans`: `YYYY-MM-DD-<topic>.md`

A spec or plan that changes scope, a contract or the roadmap is also reflected in `PRD.md`,
`ARCHITECTURE.md` or `PLAN.md`; those stay the source of truth.
